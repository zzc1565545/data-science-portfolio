## Publish

Use **Settings → Pages → Deploy from a branch → main → / (root)**.
The entry file is `index.md`; `_layouts/default.html` and `assets/style.css`
provide the presentation. `_config.yml` sets the project-site base path.
No custom domain, API key or server is required.

## Content

The site includes a short introduction, skills practiced, one ongoing project,
two charts, a research question, main findings, limitations, a repository link,
and AI disclosure. All commute values are hypothetical and explicitly labelled.
The project data contain no personal travel observations.

`PEER_REVIEW.md` records the classmate feedback supplied on 20 October 2026
and the follow-up ranking-table improvement. Earlier written rankings were
already present; the new table makes each mode's change in position explicit.
